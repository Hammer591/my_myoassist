# PhotoHipExo ±20 N·m 校验与试训

- 两个人体模型（myolegs22 / myolegs26）的绑定单元检查通过：主舱中立姿态竖直、两侧电机与髋屈伸轴同轴、固定器随股骨刚性运动、设备质量约 2.55 kg。
- 导出的实际训练模型通过两侧 −20 / 0 / +20 N·m 输出检查；缓存重载后限值保持一致。
- MirrorPPO 试训完成 65,536 步、128 轮 rollout，单环境 CPU，耗时约 3 分 10 秒。无渲染训练正常退出。
- 实际训练模型的正、侧视图：front_side_20Nm.png；可加载的 MJCF：training_model_20Nm.xml。

## 策略复测

以相同的 20 个起始种子比较第一轮更新前的策略与最后保存的策略，均采用确定性动作，保留训练时的终止条件：

| 指标 | 训练前 | 试训后 |
| --- | ---: | ---: |
| 平均每回合控制步 | 1.20 | 2.25 |
| 最长回合控制步 | 2 | 4 |
| 平均每回合奖励 | 0.433 | 0.981 |
| 最大实际电机输出绝对值（N·m） | 9.263 | 17.252 |

观测和奖励均为有限值，电机输出未超出 20 N·m。奖励和持续时间有所改善，但回合仍很短，尚未学会稳定行走。复测中终止时存在踝、膝或髋关节轨迹偏差超过原配置阈值的情况。对照原 Hippo 的 20 个零动作回合也很短（平均 1.35 步），表明这一启动现象也存在于原配置，不能归因于新外骨骼绑定。

后续训练前适合继续检查参考轨迹启动时的接触、肌肉激活初值及终止阈值；本轮保持这些条件，未为延长回合放宽阈值。
