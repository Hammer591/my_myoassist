## V2 连杆修订

末端姿态修正：左右下端固定板及绑带框的长轴在髋关节零位严格沿竖直 Y 方向，保留连杆末端的水平朝向，不再继承连杆曲线切向的倾斜。调节髋关节角度时，固定件仍随对应连杆整体转动。

根据补充近照，将左右连杆改为镜像的渐变扭转薄板：截面沿曲线切向逐渐转动，末端固定板、盖板、螺钉及绑带框采用同一末端坐标系；增加双纵向加强筋。总扭转角按用户确认设为 90°。厚度暂设 6 mm，根部至末端宽度 28–47 mm；厚度与宽度仍是建模假设，不是照片测量值。可在 build_model.py 的 P 字典调整 link_twist_deg 等参数。

扭转是固定的几何形状，本次没有引入额外扭转自由度、弹性扭转刚度或柔性动力学。原有髋关节驱动方式不变。当前模型查看器和资产包均已同步至 V2，旧版压缩包保存在上级目录 PhotoHipExo_修改扭转前.zip。

这是根据六张照片可见结构重建的第一版仿真资产，不是尺寸复刻或制造图纸。隐藏结构没有还原。

## 文件

- `L1model.xml`：设备 MJCF，三个独立顶层刚体（腰部、左右大腿连杆）。没有额外设备关节；组合时继承人体髋关节运动。
- `L1config.yaml`：myolegs26 挂接配置初稿，电机作用于 hip_flexion_r/l。
- `mesh/`：48 个二进制 STL，单位米；视觉几何关闭碰撞。绑带开孔仅保证视觉显示，不能用 MuJoCo 默认凸包模拟孔内接触。
- `preview.xml`：独立展示用模型，有两个髋部铰链和演示电机，重力设为零。
- `preview.png`：几何三视图。
- `build_model.py`：重新生成资产。修改脚本开头 P 字典可调整主要参数，运行后会覆盖生成文件。parameters.json 是参数记录。

## 使用与注册

将整个 PhotoHipExo 文件夹复制到已安装 assist_sim 的 `assist_sim/models/` 下，保留子目录：

```python
from assist_sim.registry import refresh, DEVICE_CONFIGS
refresh()
print('PhotoHipExo_L1' in DEVICE_CONFIGS)
```

在 assist_sim 仓库运行 `python examples/quickstart.py myolegs26 PhotoHipExo_L1` 检查挂接效果。

也可不注册，通过官方 `load_combined_model` API 指定本配置的绝对路径，并提供已导出的 myolegs26 人体 XML。

独立查看：

```python
import mujoco
import mujoco.viewer
m = mujoco.MjModel.from_xml_path('preview.xml')
d = mujoco.MjData(m)
with mujoco.viewer.launch_passive(m, d) as viewer:
    while viewer.is_running():
        mujoco.mj_step(m, d)
        viewer.sync()
```

坐标约定：X 向前、Y 向上、Z 向右。挂接位置是初始猜测；必须在所用人体版本中核对 pelvis/femur 的局部坐标、髋轴、左右方向并调整 YAML 的 pos/quat。当前将腰架和大腿件分别刚性挂接到人体，是理想同轴助力简化；未模拟轴线错位、绑带柔性或人机接触力。
