# 2026-10-29 参考轨迹时间轴审计与修复

审计范围：参考文件及元数据、重采样、每步相位推进、qpos/qvel目标、reset、参考回放、
自动评估缓存、命令行参数与检查点续训。基线代码为062bb78。

## 已确认的问题

1. `_imitation_index`每控制步固定加1；位置目标按该索引读取。
2. 速度目标却乘以目标速度除以参考瞬时前进速度，reset和参考回放也使用此倍率。
   若要这样改变参考速度，位置相位应同步推进相应时间；原实现没有同步。
3. 原重采样以linspace对齐两端，配置30Hz时并非精确的1/30秒间隔。
4. 训练和评估器各有一份重采样代码，存在实现分叉风险。
5. run_train按基类注册命令行参数，模仿环境特有字段（例如trajectory_curriculum.enabled）
   未进入解析器；原先给出的相关覆盖参数实际上无法使用。本次一并修复，确保续训命令有效。

## 实际参考数据核对

`short_reference_gait.npz`声明500Hz，各数组实际44,900帧；metadata.data_length为449,000，
是未同步的长度信息。加载器一直按数组真实长度重采样，该元数据差异不是此次缩放问题的原因；
本次不改写原始NPZ，仍按实际数组长度计算。

30Hz参考在两种模式下均为2694帧：

| 项目 | 旧legacy_scaled | 新fixed_rate |
|---|---:|---:|
| 每帧参考时间间隔 | 0.0333449684s | 0.0333333333s |
| 内部关节速度目标额外倍率 | 0.7787～1.2092 | 恒为1 |

以30Hz位置数据的中心数值差分作为核对量，忽略两端各2帧，速度目标RMSE（rad/s）为：

| 关节 | 旧目标 | 修复后目标 |
|---|---:|---:|
| 左髋 | 0.12073 | 0.04585 |
| 右髋 | 0.11557 | 0.05135 |
| 左膝 | 0.24944 | 0.09552 |
| 右膝 | 0.24947 | 0.10592 |
| 左踝 | 0.20572 | 0.19734 |
| 右踝 | 0.17671 | 0.19007 |

这些数值支持髋膝存在额外时序不一致，但不能作为全部轨迹偏离原因的证明。
原始dq与位置数值导数本来就有残差；右踝旧倍率恰好减小了该数值差异，取消倍率后不保证每个关节的RMSE下降。
本次没有把dq重写为数值差分以人为令指标归零，也没有声称源数据完全一致。

## 实现

- 增加`reference_motion_mode`：历史缺省legacy_scaled，当前20M配置显式fixed_rate。
- 用共同的`resample_reference_data`处理精确控制时间网格；旧模式保留原端点网格。
- qvel奖励、reset与imitation_step统一通过同一速度读取方法；fixed_rate不再计算瞬时速度倍率。
- 根部pelvis_tx速度在复制reset_qvel前设为本回合目标速度，保留任务的初始条件。
- 参考高度常量校正不改变速度；没有改动前进速度奖励、物理模型、奖励权重或网络布局。
- 评估与训练共用加载器，缓存校验参考模式，并记录模式到日志和metadata。
- 命令行先确定具体环境配置类型，再注册嵌套参数，支持关闭课程等覆盖项。
