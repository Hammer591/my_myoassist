# 无外骨骼人体：髋伸展 −35°，从零训练 3000 万步

配置：`rl_train/train/train_configs/imitation_22_NoDevice_hip35_reference_30M.json`。
模型为 `myolegs22 + NoDevice`，22 个肌肉动作，没有外骨骼执行器；`prev_trained_policy_path=null`。
旧配置及旧检查点保持兼容，新配置观测为 76 维，不能直接续训旧的 44 维策略。

## 坐标和参考核对

髋屈曲坐标的零位为模型局部关节零位，正方向为屈曲，负方向为伸展；该角度相对于骨盆，并非大腿相对世界竖直方向的角度。当前加载器没有额外的髋角符号翻转或常量偏置。

现用 `short_reference_gait.npz` 的髋角最低约为右 −29.615°、左 −27.153°，超出旧模型约 −20° 的伸展下限。旧策略在中后支撑期停留在该下限附近，限位力矩可达约 130–140 N·m，因此限位支撑是异常动作的重要原因。冻结策略直接释放下限会失稳，说明需要重新学习控制；放宽限位本身不保证恢复正常步态。

NPZ 缺少来源模型、标定和重定向元数据，不能据此宣称完整参考重定向已验证，也不能将它当成 Camargo 数据。当前只验证平面模型所用坐标、时间基准和可达范围，不给参考角度做任意偏置或截断。训练后仍需对比关节角、净关节力矩、限位力矩和地面反力。

另一个发现是：无腰关节模型的旧代码写入 `torso.quat=[1,0,0,-0.13]`，并非 −0.13 rad 的正规角度表示。其归一化旋转对应 `2*atan(-0.13)`，约 −14.814°。新配置显式采用弧度并生成单位四元数，保留该旋转方向，同时消除非单位四元数；并未把腰部强制改成参考均值。此前若把配置 −0.13 直接解释为实际腰角 −7.45°，该解释不成立。

## 新配置中的修正

- 双侧髋下限 −35°，上限保留 2.356 rad；关节限位仍启用。
- 双侧踝背屈上限 25°：参考最大约 20.63°/22.64°，旧上限约 20°。踝下限保持 −1.134 rad。
- 启动时检查参考中使用的受限铰链关节范围。容差 0.02 rad，容纳参考膝角约 0.72° 的轻微超伸；不修改膝限位。
- 观测追加未来第 1、4 个控制步的 8 个关节位置及速度，共 32 维。策略和价值网络都读取全部 76 维，左右镜像同时交换参考目标。参考采用固定时间推进；绝对水平位移不进入目标观测。
- 限位代价按 1200 Hz 物理子步计算并积分：`integral sum_j (tau_limit_j / 50 Nm)^2 dt`。逐关节平方防止抵消，子步积分防止漏掉 30 Hz 控制步中途的冲击。原有模式仍是旧配置默认值。
- 髋关节距上下限 5° 内另加平滑接近代价：`integral sum_j max(0, 1 - distance_to_limit / 5deg)^2 dt`，权重 0.5。
- 足部 touch 传感器总力超过 1.2 倍体重的代价也按物理子步积分，权重仍为 2。这是接触传感器指标，不应等同于世界坐标系垂直地面反力。
- 髋位置/速度模仿的关节权重由 0.2 提至 1；总速度模仿权重由 1 提至 2；肌肉激活代价权重由 10 降至 3，减少通过被动限位节省肌肉输出的激励。这些是待完整训练验证的起始超参数，不是已证实的最优参数。
- 保留原有轻度鲁棒性随机化及固定速度 1.25 m/s。轨迹偏离阈值仍为 0.2，未额外启用课程。

## 运行

在仓库根目录运行：

```bash
MUJOCO_GL=osmesa MPLBACKEND=Agg MPLCONFIGDIR=/tmp/myoassist_mpl \
MYOASSIST_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 \
.my_venv/bin/python -m rl_train.run_train \
  --config_file_path rl_train/train/train_configs/imitation_22_NoDevice_hip35_reference_30M.json
```

训练入口提前加载 Torch 优化器依赖，避免本机 OSMesa 与 Triton 所带 LLVM 的加载顺序冲突。使用 CPU PPO；OSMesa 用于离屏评估视频，需系统安装该库。

`30000000` 指 32 个环境合计的环境步数，不是 3000 万次 PPO 参数更新。每次 rollout 为 `32*512=16384` 步，完整 rollout 下预计实际停在 **30,015,488** 步（1832 次 rollout）。结果写入独立的 `rl_train/results/train_session_*`；程序正常结束时保存最终模型。

## 验证与复评

新增测试覆盖限位、目标索引与端点处理、镜像、旧配置兼容、四元数旋转方向、真实短程 PPO 更新和保存重载、子步物理轨迹一致性、控制步中间的限位冲击代价及越界参考拒绝。实际训练入口另以双环境 256 步验证；64 步评估测试成功输出 relaxed/strict 两种模式的报告、曲线及视频。回归测试中的多进程用例因沙箱 socket 限制单独复测通过。短测试只证明实现可运行，不能证明 3000 万步后的步态质量。

完整训练后，应同时检查：支撑中后期髋是否持续停在 −35°；髋限位力矩峰值及时间积分是否下降；髋相对骨盆角是否跟踪参考；步速、跌倒率与足底反力是否改善。肌肉广义力 `qfrc_actuator` 不包含限位约束力，不能单独作为与实验逆动力学净关节力矩的等价指标。论文曲线比较还需匹配速度、步态相位、力矩符号及体重归一化。
