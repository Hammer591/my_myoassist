# 离地附近髋、膝力矩诊断与消融训练方案

对象：`train_session_20261103-045522/model_30015488.zip`，NoDevice，strict，seed1234。
诊断输出：`rl_train/results/train_session_20261103-045522/toeoff_diagnosis_30015488/`。
本次没有修改环境动力学代码、原始训练配置或模型资产，没有启动新的完整训练。

## 结论与证据等级

已确定的局部机械机制：快速屈膝时，膝伸肌被拉长，肌肉力—速度关系提高其伸膝贡献，同时缩短中的屈肌力下降；合力矩会因此偏向伸膝。离地前的残余伸肌激活及膝屈伸肌强相消，使该效应突出。髋第二次屈髋峰更多来自腘绳肌贡献回落、股直肌贡献增加，不能用单一GRF峰解释。

闭环敏感性试验不支持“地面反力冲击是主要直接根因”：接触变软降低了力峰，膝力矩峰基本保留。肌肉募集为什么学成这样，仍是训练目标/参考跟踪等因素共同作用的假设，需要重训消融验证；不能把局部反事实当作唯一上游因果证明。

离地时关节力矩并不要求归零：摆动启动和惯性控制也需要关节力矩。本文把窄脉冲、相消、功率结构和参考偏差视为待改善线索，不把60%出现任何峰值都定义为错误。

## 对照数据的使用

Camargo 等（2021）《A comprehensive, open-source dataset of lower limb biomechanics in multiple conditions of stairs, ramps, and level-ground ambulation and transitions》，DOI 10.1016/j.jbiomech.2021.110320。

该实验数据集的OpenSim逆动力学力矩/功率及EMG是比外骨骼辅助力矩更适合的比较对象，但不能把实验净关节力矩与本模型qfrc_actuator不加区分地等同。

论文方法：运动捕捉6 Hz四阶零相位低通，GRF 15 Hz十阶零相位低通；力矩/功率按体质量归一化；以足跟标记速度零点定义步态起点。本模型目前用承重触地事件，不是完全相同的足跟事件。当前髋屈曲方向为正，而论文图4髋力矩伸展为正，比较髋力矩需翻转符号；膝力矩伸展方向为正。

当前实际速度约1.136 m/s，不能只用标称1.25 m/s的实验曲线判断幅值。后续应取1.10/1.15 m/s与1.25 m/s条件，或先修正速度跟踪。此次未下载多GB受试者原始数据，也没有声称获得了逐点实验参考误差。

当前1200 Hz原始膝平均曲线的55–67%正峰，右13.89、左26.28 N·m；先6 Hz低通后的同窗口峰约右7.02、左8.97 N·m。这说明显示处理会明显影响窄峰，但单独低通输出不等价于论文从滤波运动学/GRF进行逆动力学的整套处理，也不能代替策略改进。

## 肌肉分解与同状态反事实

全部分解在独立MjData上同步forward；逐肌肉力×力臂的和与qfrc_actuator核对，绝对容差1e-7 N·m。

周期60%的主要结果：

| 量 | 右 | 左 |
|---|---:|---:|
| 原膝合肌肉力矩 N·m | +10.58 | +22.50 |
| 同姿态/激活，肌肉增益中的速度设0 N·m | −32.06 | −18.70 |
| 同姿态/速度，将激活瞬时设为当前兴奋指令 N·m | −9.94 | +17.03 |
| 膝关节外部被动力矩 N·m | +0.33 | +0.36 |
| 实际屈膝速度 rad/s | −6.66 | −7.27 |
| 参考屈膝速度 rad/s | −5.80 | −6.01 |
| 同侧垂直GRF N | 86.48 | 99.83 |

速度设0的反事实保留实际肌肉长度、力臂、激活，只改变局部力—速度增益；它不是可行步态，不是建议删掉肌肉力—速度关系。

例如右侧60%：股四头肌vasti伸膝贡献56.2 N·m，速度设0后48.3；腘绳肌屈膝贡献−41.8，速度设0后−54.9；腓肠肌贡献−9.3，速度设0后−21.3。伸肌增强和屈肌减弱叠加，使净力矩变化远大于单个肌肉的增幅。

右vasti从55%到60%，激活约0.39降到0.18，当前兴奋从0.27降到0.05，但力矩仍从46.3增到56.2 N·m。模型激活/去激活时间常数为0.01/0.04 s，30 Hz控制不能把残余激活瞬间清掉。即时激活反事实只解释一部分，左侧仍有正峰；把所有激活动力学加快还可能增加髋峰，不能当作直接修复。

髋侧55%到62%：右腘绳肌伸髋贡献约−46.8→−27.3 N·m，股直肌屈髋约6.1→14.0；左约−50.9→−27.3、5.6→20.8。共同造成屈髋合力矩回升。

被动力矩在55–67%绝对值小于0.4 N·m，不足以抵消数十N·m的波形，因此“只是漏加被动力矩”不能解释该峰。qfrc_actuator中的肌肉执行器力还可包含肌肉模型自身的弹性成分，它不等同于纯激活依赖力。

参考索引按控制步连续前进，未发现离地时的参考跳帧。参考膝dq与30 Hz q有限差分的RMS差约0.09–0.10 rad/s，不能据此认定存在大幅导数错误。实际速度仍有约15–21%的局部超调。

## 地面反力、足部观测和跖趾限位的闭环对照

所有试验冻结同一策略、同一seed，完整回放19.47 s至参考耗尽；只有指定干预变化。每个工况独立按同一GRF事件规则对齐，周期数右16/左15。下面是55–67%窗口的周期平均力矩正峰，GRF为全回放瞬时峰：

| 工况 | 右/左膝峰 N·m | 右/左髋峰 N·m | 右/左GRF峰 N |
|---|---:|---:|---:|
| 原始 | 13.89 / 26.28 | 50.84 / 57.90 | 1277.6 / 1133.2 |
| 接触solref时间0.02→0.04 s | 12.92 / 27.45 | 47.61 / 56.53 | 985.6 / 992.7 |
| MTP上限30→40° | 14.07 / 27.41 | 50.18 / 58.11 | 1277.6 / 1150.1 |
| 策略足底观测50 ms低通 | 15.53 / 25.01 | 50.13 / 56.04 | 1278.5 / 1186.3 |

接触变软后GRF峰下降，但并未消除力矩峰；这降低了“GRF尖峰主导此异常”的可能性，但不能排除更广泛的足部几何、COP或接触建模影响。

此前未触发限位的结论只针对髋、膝、踝六个主要关节。新增检查发现MTP原上限约30°，离地前约57.5–58%确有跖趾限位反力，峰约右6.26、左6.38 N·m。放宽至40°降低了MTP反力，膝/髋峰仍保留，故它是足部建模的次级问题，尚不是本次峰值的主要解释。没有把这个放宽应用到正式配置。

足底观测低通试验针对现有76维人体观测的39:43四个足底传感器输入；物理、奖励和参考不变。峰值未显著消失，未支持“感知接触跳变单独导致此峰”。

## 解决方案：先训练目标，再决定接触参数

### A：把拮抗惩罚扩展到膝

配置：`rl_train/train/train_configs/imitation_22_NoDevice_hip35_knee3_toeoff_antagonism_30M.json`。

现有正则只约束髋部相消，膝可以以较高的屈伸肌张力彼此抵消来满足角度跟踪和净力矩平滑。新增双膝到原有antagonist_joints；保留20 N·m共收缩余量、100 N·m归一化。遗留键名仍为hip_antagonist_moment_penalty，但计算实际支持列表中的所有铰链关节。

关节数从2变4，平均成本会除以4，所以权重0.1→0.2以维持每个髋的原贡献，同时新增膝成本。它不把正常负功率或正常伸膝力矩当错误，不强制60%力矩为0，也不改变肌肉自然动力学。

### B：减小离地时膝速度超调

配置：`rl_train/train/train_configs/imitation_22_NoDevice_hip35_knee3_toeoff_velocity_30M.json`。

双膝qvel模仿相对权重0.1→0.5，其余保持基线。目标是减小−6.66/−7.27相对参考−5.80/−6.01 rad/s的局部超调，从运动学侧减轻力—速度放大。现有归一化qvel奖励会重新分配关节相对权重，不等于总qvel奖励直接扩大5倍；应检查髋、踝跟踪是否退化。

### AB：组合，作为两种单项消融后的候选

配置：`rl_train/train/train_configs/imitation_22_NoDevice_hip35_knee3_toeoff_combined_30M.json`。

A、B、AB都继承结构性镜像、膝+3°限位及其他平滑目标；不改接触刚度、不放宽MTP，也不增加生理上未经验证的力矩参考。三个文件已完成环境构建、模型加载及32步有限奖励验证，没有训练出新策略，也不能声称问题已解决。

启动示例（从头30M）：

```bash
.my_venv/bin/python -m rl_train.run_train \
  --config_file_path rl_train/train/train_configs/imitation_22_NoDevice_hip35_knee3_toeoff_antagonism_30M.json
```

更省时的第一轮可从当前结构匹配的checkpoint做短程适配，但A、B和对照必须从同一checkpoint、相同预算和种子开始，不能把不同训练预算的结果当因果对照。正式结论仍需要多个训练种子。

## 验收

- 使用同一触地规则，保留原始与统一6 Hz显示处理的力矩/功率；同速度、符号、质量归一化比较Camargo。
- 检查55–67%窄峰、膝角速度超调、膝拮抗贡献及单周期离散度，而不只看平均曲线。
- 检查三项收益是否伴随更早合理的伸肌去激活；不能通过全腿弱化或任务失败压低力矩。
- 任务完成率、速度误差、全周期轨迹误差、六大关节及MTP限位、真实GRF尾部冲击均作为约束。
- 完整覆盖初始相位，包含此前seed1236短程失效；不只展示成功seed。
- 如果A/B无效，再检查肌肉参数标定、肌腱路径/力臂连续性、足部几何与COP，及引入经过配准的实验净关节力矩参考；不要直接删掉正常力—速度曲线。
