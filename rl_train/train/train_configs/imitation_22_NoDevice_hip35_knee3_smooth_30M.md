# 无外骨骼人体策略：膝限位与肌肉力矩调整

对应配置：`imitation_22_NoDevice_hip35_knee3_smooth_30M.json`。

从仓库根目录启动：

```bash
.my_venv/bin/python -m rl_train.run_train \
  --config_file_path rl_train/train/train_configs/imitation_22_NoDevice_hip35_knee3_smooth_30M.json
```

该配置从头训练 30,000,000 步，32 个环境，控制 30 Hz、物理 1200 Hz；
`prev_trained_policy_path=null`。保留原 hip35 模型范围、参考轨迹、网络和鲁棒性训练设置。
本次没有启动完整训练。

## 奖励与范围

| 调整 | 设置 | 目的 |
|---|---|---|
| 双膝伸直端限位 | 0° → +3°，屈曲端保持约 −145° | 小幅释放伸直端范围 |
| 髋/膝接近限位惩罚 | 双膝加入原髋关节名单；5° 裕量；权重 0.5 → 2.0 | 膝从 −2° 开始受罚，鼓励策略在碰到 +3° 前纠正 |
| 实际限位力矩惩罚 | 保留子步平方力矩，50 N·m 归一化，权重 1 | 继续约束实际触发；放宽范围并不保证新策略不触发 |
| 主动关节力矩变化率 | 双侧髋/膝/踝；600 N·m/s 归一化；权重 0.03 | 限制快速变化，子步积分以覆盖控制步之间的抖动 |
| 肌肉兴奋变化 | 实际肌肉 ctrl 相邻控制步差；0.1 归一化；权重 0.02 | 抑制肌肉募集指令反复跳变 |
| 髋拮抗力矩 | 双髋；允许 20 N·m 相消余量，100 N·m 归一化；权重 0.1 | 温和约束此前下凹阶段观察到的大幅正负肌肉力矩相消 |

三项新增惩罚默认权重均为零，只有新配置启用。肌肉力矩投影排除非肌肉外骨骼执行器；
原有肌肉努力、速度和运动学模仿目标保留。

### 数学定义

力矩变化率（物理步长 `h`）：

`r_rate = -w_rate * sum_substeps(h * mean(((tau[k]-tau[k-1])/(h*600))**2))`

`tau` 为所选人体关节的主动肌肉合力矩，不含被动、接触或限位反力。
相邻控制步之间继续作差；reset 后第一个物理样本仅建立基准，不与上一回合作差。

兴奋变化（控制步长 `dt`）：

`r_excitation = -w_u * dt * mean(((ctrl[t]-ctrl[t-1])/0.1)**2)`

使用经执行器处理后、实际送入肌肉模型的 `ctrl`，不混入设备通道。
每个回合第一次控制没有此项差分成本。

髋拮抗力矩（每条腿分别计算）：

`P = sum(max(muscle_moment, 0))`

`N = -sum(min(muscle_moment, 0))`

`r_antagonist = -w_ant * sum_substeps(h * mean((max(min(P,N)-20,0)/100)**2))`

该项针对肌肉贡献过度相消，保留共收缩余量；不按某个步态窗口强制力矩为正，
也没有注入人为髋力矩参考曲线。它是针对先前肌肉分解结果的训练假设，
不能保证下凹消失。由于腘绳肌、股直肌跨关节，重训后必须同时检查膝轨迹与稳定性。
论文提供的是负荷/代谢与任务共同优化的思路，这三个正则不是该论文的原始公式。

已有激活差分奖励的跨回合历史现在也会在 reset 后清空，避免上一回合末尾影响新回合。

## 重训后验收

在相同速度、相同参考运动和多个初始相位下检查：

- 任务完成率、平均速度及轨迹误差不明显退化。
- 逐物理子步统计双膝非零限位力矩占比，目标为零，不能只看角度曲线。
- 双髋及其他关节的力矩变化率 RMS/高分位与单周期波动幅值下降。
- 单独检查左髋早期 0–20% 波动与 35–60% 下凹；统一左右周期事件定义。
- 比较肌肉努力、拮抗贡献和膝运动，避免通过少走路或改变步态任务换取平滑。
- 保留原始曲线；绘图低通结果不作为真实动力学改善的唯一证据。
