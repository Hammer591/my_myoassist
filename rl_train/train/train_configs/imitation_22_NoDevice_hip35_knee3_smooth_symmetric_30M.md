# 结构性镜像对称人体策略

从仓库根目录启动新的 30M 步训练：

```bash
.my_venv/bin/python -m rl_train.run_train \
  --config_file_path rl_train/train/train_configs/imitation_22_NoDevice_hip35_knee3_smooth_symmetric_30M.json
```

该配置继承 `imitation_22_NoDevice_hip35_knee3_smooth_30M.json` 的力矩变化率、
肌肉兴奋变化、髋拮抗惩罚以及双膝 +3° 限位和接近边界惩罚。
仍为 32 环境、30 Hz 控制、1200 Hz 物理；不加载旧策略，从头训练。

## 结构

启用 `policy_params.custom_policy_params.structural_symmetry=true`。
对同一个人体 MLP `f` 进行共享权重的双分支计算：

`mu(s) = (f(s) + M_action(f(M_observation(s)))) / 2`

因此 `mu(M_observation(s)) = M_action(mu(s))` 在浮点精度范围内恒成立。
这并不要求同一时刻左右腿动作相同，允许正常交替步态。

镜像映射从所用模型的执行器名和配置的观测键生成，覆盖当前关节位置、速度、
肌肉激活、足部传感器及每个未来参考观测窗口。该模型是矢状面模型，现有映射为
左右索引置换，不含三维外展、旋转的符号变换。
映射在构建时检查尺寸、置换完整性和两次镜像还原性，并作为 buffer 随模型保存。

探索分布的有效 log_std 为：

`effective_log_std = (log_std + log_std[M_action]) / 2`

对应的左右肌肉标准差严格共享。采样、PPO 的 log_prob/entropy 计算和推理均使用该值。
它保证镜像高斯分布，而非每次独立随机采样的两侧动作都相同。
保留原长度的参数向量，避免改变默认非对称策略和设备策略的接口。

新配置将 `mirror_coef` 设为 0：结构已保证动作均值镜像关系，无须再为同一关系执行
额外的镜像损失优化。Critic 仍为原网络，未强制其对称。
Actor 每次进行两次 MLP 前向计算，参数量不增加；整体训练耗时取决于环境与优化开销。

## 兼容性

- 结构性对称默认关闭，旧模型和旧配置保留原推理路径。
- 新 checkpoint 保存并恢复结构设置、映射 buffer、优化器和共享探索行为。
- 续训/评估时配置必须匹配 checkpoint 的结构开关及观测/动作映射，不会把旧普通
  checkpoint 静默当成结构对称策略。要切换结构请从本配置新建训练。
- 当前结构开关针对人体独立 Actor；尚未扩展到人体与外骨骼联合 Actor。
- 冻结人体转移工具目前只复制原始 MLP，因此会拒绝结构性对称人体 checkpoint，
  避免复制时丢失双分支投影。以后将这种人体策略用于冻结人体外骨骼训练，需要先
  扩展接收端结构与保存加载流程。

## 验证与限制

测试覆盖随机镜像输入、确定性预测、左右标准差、镜像动作 log_prob 与 entropy、
PPO 梯度更新后对称性、保存/加载/继续训练，以及旧结构兼容与非法映射拒绝。

结构保证的是镜像状态到镜像动作分布的映射。参考运动不对称、初始状态不对称、
接触差异或独立扰动仍可能导致实际步态曲线不完全对称。重新训练后仍应在统一的
触地事件定义下比较左右同相位角度、力矩与支撑负荷，并检查速度、稳定性和膝限位。
本次只完成实现和短程训练验证，没有启动完整 30M 步训练。
